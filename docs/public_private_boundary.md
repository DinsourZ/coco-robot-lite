# Public/private boundary

This clean-room demo is designed to explain a project concept without publishing operational internals.

| Included here | Intentionally excluded |
| --- | --- |
| Local fixture data | Operational telemetry and databases |
| Static dashboard interactions | Real service calls and remote commands |
| Generic ESP32-S3 peripheral exercises | Production firmware and complete control behavior |
| Generic wiring concepts | Device enrollment and identity material |
| Safety cautions | Production safety-agent or emergency-stop implementation |
| High-level architecture | Private backend, infrastructure, and deployment details |

No private repository history was copied into this repository. The public project must remain independent: contributions should be reviewed as public demo material, not synchronized from a production codebase.

Before every release, review staged files for non-public addresses, identifiers, configuration, operational screenshots, logs, database files, and authentication material. If anything is ambiguous, do not publish it until its origin and safety are confirmed.
