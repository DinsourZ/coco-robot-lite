# Demo setup

## Dashboard-first presentation

1. Install a maintained Node.js release and npm.
2. Enter `web-demo`.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local address printed by Vite.

The page is fully populated from bundled fake data. No hardware, account, service, or network integration is needed.

## Suggested walkthrough

1. Point out the **Demo Mode Only** badge.
2. Show the simulated readiness and device-health cards.
3. Explain that telemetry changes are presentation fixtures.
4. Use the control experiment and show that it only updates a local UI message.
5. Close with the public/private boundary and the supervised firmware exercises.

## Firmware presentation

Prefer recorded serial output or an unpowered board for a general audience. For a live servo demonstration, follow the separate example README, remove attached mechanisms, limit energy, and keep a physical disconnect accessible.
