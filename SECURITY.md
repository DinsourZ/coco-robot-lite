# Security policy

CoCo Robot Lite is a public educational demo. It does not contain or claim to provide a production security implementation, and it must not be used as a production system.

If you discover a disclosure risk or another security issue in this repository, please open a GitHub issue with a minimal, non-sensitive description. Do not include exploit material that would expose an active system.

Never submit real tokens, private keys, device credentials, server configuration, non-public addresses, operational logs, or production data in an issue or pull request. If a report itself requires sensitive evidence, first ask the maintainer for a suitable private reporting channel without posting that evidence publicly.

The demo has no real device enrollment, remote command path, user authentication flow, private service integration, or production safety logic. Its interface values are local fixtures and its firmware is intentionally limited to supervised learning exercises.
